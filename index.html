    Build

    • Jenkins
    • Azure DevOps
    • Maven

    • GitHub Actions
    En Tsoft

    En Master Pet
    Integración continua con GitHub Actions: cada cambio dispara el build de la tienda y la suite completa de pruebas.

  4. Etapa 04 / 08

    Pruebas

    • JUnit
    • Selenium
    • JMeter
    • Postman
    • Cucumber
    • Playwright
    En Tsoft
    Automaticé pruebas funcionales, de regresión, de carga y de APIs REST con JUnit, Selenium, JMeter, Postman y Cucumber con Gherkin (BDD).
    En Master Pet
    Más de 250 pruebas automatizadas (unitarias, de integración HTTP y end-to-end con Playwright) que cubren concurrencia, pagos duplicados y recuperación ante fallos.

    Buena práctica

    Desarrollo guiado por pruebas (TDD)

    Cada corrección empieza con una prueba que reproduce el defecto, sigue con el cambio mínimo que la hace pasar y queda en la suite como prueba de regresión (rojo, verde, refactor).
